# AI Kitchen Platform

Monorepo for the AI Kitchen graduation project.

- `backend/` — NestJS, GraphQL, Prisma, and PostgreSQL API.
- `frontend/` — reserved for the web frontend.
- `mobile-app/` — reserved for the mobile application.

Backend setup is documented in `backend/README.md`. Copy `backend/.env.example` to `backend/.env` and configure local secrets before running it.
